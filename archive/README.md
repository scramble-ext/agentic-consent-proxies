# Archived proxies

Proxies that ScrambleID no longer develops. Their guides, templates and checksums stay here, unchanged, for
deployments that still run them.

| Proxy | Last version | Replaced by |
|---|---|---|
| Consent Notification Proxy (callback proxy) | [1.0.4](callback-proxy/releases/1.0.4/) | The [ScrambleID Edge Proxy](../README.md#edge-proxy) with `callbacks` on. To switch, see "Moving from the older proxies" in the edge proxy's deployment runbook. |

Paths in the archived guides, such as `callback-proxy/releases/<version>/deploy/`, are relative to this
`archive/` folder.
